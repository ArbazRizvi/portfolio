Kids Guard Application (Final Year Project)

Problem

Parents require a reliable, modern solution to ensure their children's digital and physical safety, from monitoring online conversations for cyberbullying to knowing their real-time location.

Solution

A comprehensive Android application with two modes (Parent & Child). Key features include real-time location tracking, geofencing, app blocking, screen time limits, and an advanced AI-powered cyberbullying detection module that scans chat messages locally on the child's device for potential threats and alerts the parent.

Tech Stack

Android (Java) Firebase Auth Firestore Python (Flask API) BERT Model

Key Achievement

This project earned an 'A' Grade. The fine-tuned BERT model for cyberbullying detection achieved 92% accuracy on our custom test dataset, demonstrating a successful application of NLP to a real-world safety problem.

Cardiovascular Disease Risk Classifier

Objective

A key project from the Stanford/DeepLearning.AI specialization. The goal was to build and evaluate multiple machine learning models to predict the 10-year risk of cardiovascular disease (CVD) based on a patient's clinical data.

Methodology

  1. Data Preprocessing: Cleaned and preprocessed the dataset (handling missing values, feature scaling with StandardScaler, one-hot encoding categorical features).
  2. Model Training: Trained several classifiers (Logistic Regression, K-Nearest Neighbors, Support Vector Machine, and Random Forest) using Scikit-learn.
  3. Evaluation: Compared models based on Accuracy, Precision, Recall, and F1-Score.
  4. Hyperparameter Tuning: Used GridSearchCV to find the optimal parameters for the best-performing model (Random Forest).

Tech Stack

Python Scikit-learn Pandas NumPy Matplotlib Jupyter Notebook

Result

The optimized Random Forest classifier achieved the highest F1-score (89%), demonstrating a strong understanding of the end-to-end machine learning pipeline from data ingestion to model tuning and evaluation.

Q-Learning GridWorld Solver

Objective

To prepare for the "Planning & Reinforcement Learning" module (12 Credits) of the Master's curriculum by implementing core RL algorithms from scratch without relying on high-level libraries.

Methodology

Implemented a Q-Learning algorithm (Off-policy TD control) to solve a navigation problem. The agent explores a grid environment using an Epsilon-Greedy strategy, learning to avoid static hazards and reach a goal state by maximizing cumulative rewards based on the Bellman Equation.

Tech Stack

Python NumPy Mathematics (Bellman Eq)

Key Concept

Demonstrates the fundamental tradeoff between Exploration (discovering new paths) and Exploitation (using the best-known path) in AI decision-making.
